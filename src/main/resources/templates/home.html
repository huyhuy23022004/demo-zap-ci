DevSecOps Pipeline

Ứng dụng demo tích hợp OWASP ZAP (DAST) và SpotBugs (SAST) vào CI/CD pipeline. Mỗi lần push code, hệ thống tự động quét bảo mật theo 2 luồng song song.

Kiến trúc bảo mật

3 tầng phòng thủ được tích hợp vào quy trình CI/CD

SAST — Hộp trắng

SpotBugs + FindSecBugs phân tích mã nguồn tĩnh, tìm lỗ hổng bảo mật trước khi code chạy. Phát hiện hardcode mật khẩu, XSS trong template.

DAST — Hộp đen

OWASP ZAP Full Scan giả lập hacker tấn công ứng dụng đang chạy. Phát hiện XSS, SQL Injection, CSRF, thiếu Security Headers.

Unit Test bảo mật

JUnit + MockMvc kiểm tra phân quyền RBAC: Role USER không thể truy cập Admin, chỉ ADMIN mới vào được dashboard quản trị.
